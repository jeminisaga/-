プライバシー

写真は、端末から出ません。

うちの子の写真を他人のサーバーに預けるのは、気持ちのいいことではありません。だからこの拡張には、預ける先がありません。

  • 写真も設定も、ブラウザのなかの chrome.storage.local だけに保存されます。
  • アカウント登録もログインもありません。作るものが何もないからです。
  • 使用時間の集計も端末のなかで完結します。どこにも送られません。
  • 拡張を消せば、写真も一緒に消えます。回収する場所がありません。

よくある質問

たぶん、これが気になる。

結局、拡張を消して続けませんか。
消せます。誰にも止められません。ただ、消す相手がうちの子だと、手が止まる人が多いです。この拡張が賭けているのはそこ一点です。強制力ではなく、気持ちのほうです。
スクリーンタイムとどう違いますか。
スクリーンタイムには「あと15分」があります。押せば続きます。うちの子には解除ボタンがありません。時間が過ぎるのを待つ以外にやることがない、という状態を作るのが目的です。
写真をアップロードするのが心配です。
アップロードしません。写真はブラウザのなかに保存されるだけで、外に出る経路がありません。送信先のサーバーそのものが存在しないので、漏れようがない作りです。
仕事でYouTubeを使います。困りませんか。
対象サイトは設定で外せます。YouTubeだけ外して、XとInstagramだけ見張ってもらう、といった使い方ができます。
お金はかかりますか。
かかりません。課金も広告もありません。作った本人が使うために作ったものです。

はじめる

今日から、
うちの子に見張ってもらう。

いまは開発者モードで読み込んで使えます。Chrome ウェブストアでの公開は準備中です。

  1. ソースコードをダウンロードして、好きな場所に置きます。
  2. Chrome で chrome://extensions を開きます。
  3. 右上の「デベロッパーモード」をオンにします。
  4. 「パッケージ化されていない拡張機能を読み込む」からフォルダを選びます。
  5. ツールバーに 🐾 が出たら完了です。うちの子を登録してください。
