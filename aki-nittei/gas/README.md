# 空き日程を Googleカレンダーにつなぐ（段階2）

Google Apps Script（Googleの無料の仕組み）の「ウェブアプリ」として動かす。
Google Cloud の登録や「テスト利用者」の設定は要らない。用意するのは Googleアカウントだけ。

## 仕組み（1行）

いくみんさんの Googleアカウントの中で小さなプログラムが動き、本人のカレンダーを読んで画面に渡す。
予定は本人のアカウントの外に出ない。

## 誰のアカウントで作るか

| 作り方 | 良い点 | 注意 |
|---|---|---|
| **A. いくみんさんのアカウントで作る（おすすめ）** | 予定が本人の外に出ない。カレンダーの共有設定が要らない | 設置作業は本人のアカウントにログインした状態でやる（PCが要る。隣で一緒にやるのが早い） |
| B. なかあきのアカウントで作り、いくみんさんのカレンダーを共有してもらう | 設置・更新をこちらで完結できる | 本人のカレンダーがこちらから見える状態になる。`Code.gs` の `CALENDAR_IDS` に本人のメールアドレスを入れる |

## 設置手順（15分。PCで）

1. 使うアカウントで https://script.google.com/ を開く → **新しいプロジェクト**
2. 左上の「無題のプロジェクト」を **空き日程** に変える
3. 左の `コード.gs` を開き、中身を全部消して、この `Code.gs` の中身を貼る
4. 左の「ファイル」の **＋** → **HTML** → 名前を `index` にする → 中身を全部消して、この `index.html` の中身を貼る（`.html` は自動で付く）
5. 右上の **デプロイ** → **新しいデプロイ**
   - 左上の歯車で種類を **ウェブアプリ** にする
   - 説明: 空き日程
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ**（他の人に画面を見せたいときだけ「Googleアカウントを持つ全員」）
   - **デプロイ**
6. 「アクセスを承認」→ アカウントを選ぶ → 「このアプリは Google で確認されていません」と出たら **詳細** → **空き日程（安全ではないページ）に移動** → **許可**
   - 自分で作ったプログラムに自分で許可を出しているだけ。文面が怖いが問題ない
7. 出てきた **ウェブアプリのURL** をコピーして、本人の携帯に送る（LINEなど）
8. 携帯の Safari でそのURLを開く → 動くことを確認 → 共有ボタン → **ホーム画面に追加**

## 動かないとき

| 症状 | 見るところ |
|---|---|
| 「権限がありません」「アクセスできません」 | 携帯のブラウザが別の Googleアカウントでログインしている。アカウントを切り替える。または手順5の「アクセスできるユーザー」を見直す |
| 予定を読めませんでした、と赤く出る | エディタで `testGetEvents` を選んで **実行** → 下の「実行ログ」にエラーが出る。それを見せてもらう |
| 空きは出るが、予定が反映されていない | 「読んだ予定を見る」で読めている予定を確認。別のカレンダーに入れている予定なら `CALENDAR_IDS` を指定する |
| 祝日や誕生日のせいで1日つぶれる | 設定の「終日の予定がある日は出さない」を外す。または祝日カレンダーは「自分のカレンダー」ではないので通常は読まれない |
| Googleのログイン画面が毎回出る | 携帯の Safari で Googleにログインしたままにする。プライベートブラウズだと毎回聞かれる |

## 更新のしかた（画面を直したあと）

1. `node build-single.mjs gas/index.html --gas` で `gas/index.html` を作り直す（このリポジトリで）
2. Apps Script の `index.html` に貼り直す（`Code.gs` を変えたときはそちらも）
3. **デプロイ** → **デプロイを管理** → 鉛筆 → バージョン: **新バージョン** → **デプロイ**
   - URLは変わらない。ホーム画面のアイコンもそのまま

## 分かっている制約

- 画面の URL が `script.google.com/macros/s/…/exec` と長い。ホーム画面に置けば気にならない
- 画面の上に「このアプリケーションは Google ではなく、別のユーザーによって作成されたものです」と出る。消せない
- 予定を読むのに1〜3秒かかる（「予定を読んでいます…」と出る）
- 設定（時間帯、文面）は携帯の中に保存される。携帯を替えたら設定し直し
