# 空き日程を Googleカレンダーにつなぐ（段階2）

Google Apps Script（Googleの無料の仕組み）の「ウェブアプリ」として動かす。
Google Cloud の登録や「テスト利用者」の設定は要らない。

## 仕組み（1行）

URLを開いた人が自分の Googleアカウントでログインすると、**その人自身のカレンダー**を読んで空きを出す。
設置は なかあき のアカウントで1回。いくみんさんは URL を開いてログインするだけ。
予定は本人のアカウントの中で読まれ、なかあき からは見えない。

## 設置手順（なかあき が PC で。15分）

1. https://script.google.com/ を開く → **新しいプロジェクト**
2. 左上の「無題のプロジェクト」を **空き日程** に変える
3. 左の `コード.gs` を開き、中身を全部消して、この `Code.gs` の中身を貼る
4. 左の「ファイル」の **＋** → **HTML** → 名前を `index` にする → 中身を全部消して、この `index.html` の中身を貼る（`.html` は自動で付く）
5. 右上の **デプロイ** → **新しいデプロイ**
   - 左上の歯車で種類を **ウェブアプリ** にする
   - 説明: 空き日程
   - 次のユーザーとして実行: **ウェブアプリにアクセスしているユーザー** ← ここが「Googleログインで使える」の要
   - アクセスできるユーザー: **Googleアカウントを持つ全員**
   - **デプロイ**
6. 出てきた **ウェブアプリのURL** をコピーする
7. まず自分の携帯で開いて、下の「初めて開いたとき」の画面を通り、自分の予定で動くことを確かめる
8. URL をいくみんさんに送る（LINEなど）

## いくみんさんが初めて開いたとき（携帯）

1. URL を開く → Google のログイン画面が出たらログインする
2. 「空き日程 が Google アカウントへのアクセスをリクエストしています」→ **許可**
   - その前に「このアプリは Google で確認されていません」と出たら **詳細** → **空き日程（安全ではないページ）に移動**
   - 個人で作った道具なので Google の審査を受けていない、という意味。予定が外に出ることはない
3. 画面が出たら「来週」→「空きを出す」
4. 共有ボタン → **ホーム画面に追加**

この許可は1回だけ。次からはホーム画面から開くだけで動く。
画面の下に「○○@gmail.com のカレンダーを読んでいます」と出るので、違うアカウントなら「別のアカウントで開く」を押す。

## 動かないとき

| 症状 | 見るところ |
|---|---|
| ログインしたのに「権限がありません」 | 手順5の「アクセスできるユーザー」が「自分のみ」になっている。「Googleアカウントを持つ全員」にして、デプロイし直す |
| 予定を読めませんでした、と赤く出る | 携帯の別ブラウザで開き直す。直らなければ、なかあき が自分のアカウントで同じ操作をして再現するか見る |
| 空きは出るが、予定が反映されていない | 「読んだ予定を見る」で読めている予定を確認。別のカレンダーに入れている予定なら、`Code.gs` の `CALENDAR_IDS` にそのカレンダーの ID を入れる（本人のカレンダーを本人が読むので、共有設定は不要） |
| 祝日や誕生日のせいで1日つぶれる | 設定の「終日の予定がある日は出さない」を外す。祝日カレンダーは「自分のカレンダー」ではないので通常は読まれない |
| Googleのログイン画面が毎回出る | 携帯の Safari で Google にログインしたままにする。プライベートブラウズだと毎回聞かれる |
| 違う人の予定が出る | 携帯のブラウザが別の Googleアカウントでログインしている。「別のアカウントで開く」で切り替える |

## 更新のしかた（画面を直したあと）

1. `node build-single.mjs gas/index.html --gas` で `gas/index.html` を作り直す（このリポジトリで）
2. Apps Script の `index.html` に貼り直す（`Code.gs` を変えたときはそちらも）
3. **デプロイ** → **デプロイを管理** → 鉛筆 → バージョン: **新バージョン** → **デプロイ**
   - URLは変わらない。ホーム画面のアイコンもそのまま。相手の再許可も要らない

## 分かっている制約

- URL を知っている人は誰でも開ける。ただし見えるのは**その人自身の予定だけ**なので、漏れて困るものはない
- 画面の URL が `script.google.com/macros/s/…/exec` と長い。ホーム画面に置けば気にならない
- 画面の上に「このアプリケーションは Google ではなく、別のユーザーによって作成されたものです」と出る。消せない
- 予定を読むのに1〜3秒かかる（「予定を読んでいます…」と出る）
- 設定（時間帯、文面）は携帯の中に保存される。携帯を替えたら設定し直し

## 別のやり方（参考）

いくみんさん本人のアカウントで設置し、「次のユーザーとして実行: 自分」「アクセス: 自分のみ」にすると、URL を知っていても本人以外は開けない。
その代わり設置作業を本人のアカウントで行う必要がある（隣で一緒に PC を操作する）。
