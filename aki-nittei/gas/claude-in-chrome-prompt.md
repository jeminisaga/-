# Claude in Chrome に渡すプロンプト（Apps Script への設置）

以下を丸ごと Claude in Chrome に貼る。前提: Chrome で Google にログイン済み。

---

Google Apps Script に「空き日程」というウェブアプリを設置してほしい。コードは GitHub にある。手順は必ずこの順で、各ステップの確認を満たしてから次へ進むこと。

## 使うファイル（公開リポジトリ。ログイン不要）

- Code.gs: https://raw.githubusercontent.com/jeminisaga/-/claude/available-schedule-output-caafpf/aki-nittei/gas/Code.gs
- index.html: https://raw.githubusercontent.com/jeminisaga/-/claude/available-schedule-output-caafpf/aki-nittei/gas/index.html

## 大事な注意

- エディタにコードを**1文字ずつ入力しないこと**。Apps Script のエディタは括弧を自動で閉じたり字下げを入れるので壊れる。必ず「全選択 → 貼り付け（Ctrl+V / Cmd+V）」でまとめて入れる
- 貼り付けの手順: 上の raw の URL を新しいタブで開く → ページ内で全選択（Ctrl+A / Cmd+A）→ コピー（Ctrl+C / Cmd+C）→ Apps Script のタブに戻る → エディタ内をクリック → 全選択（Ctrl+A / Cmd+A）→ 貼り付け（Ctrl+V / Cmd+V）
- 貼り付けができない場合は、私（人間）に「エディタをクリックして Ctrl+V を押してください」と頼んで待つこと。自力で入力しないこと
- Google の許可画面（「権限を確認」「このアプリは確認されていません」「許可」）が出たら、**ボタンを押さずに止まって私に知らせる**。私が押す

## 手順

1. https://script.google.com/home を開き、「新しいプロジェクト」を押す
   - 確認: エディタが開き、左に `コード.gs` がある
2. 左上の「無題のプロジェクト」をクリックし、名前を `空き日程` にして「名前を変更」
   - 確認: 左上が「空き日程」になっている
3. `コード.gs` に Code.gs を貼り付ける（上の注意のとおり、全選択 → 貼り付け）
   - 確認: エディタの1行目が `/**` で、`function getEvents(startKey, endKey)` という行が含まれている。`function myFunction()` が残っていないこと
4. 左の「ファイル」の横の「＋」→「HTML」→ 名前に `index` と入力して Enter
   - 確認: 左に `index.html` ができ、エディタに `<!DOCTYPE html>` などの雛形が出ている
5. `index.html` に index.html を貼り付ける（全選択 → 貼り付け）
   - 確認: エディタの1行目が `<!-- 生成物。` で始まり、`<title>空き日程</title>` という行が含まれている
6. Ctrl+S（Cmd+S）で保存
7. 左の「サービス」の横の「＋」→ 一覧から「Google Calendar API」を選び「追加」
   - 確認: 左の「サービス」の下に「Calendar」が出ている
8. 右上「デプロイ」→「新しいデプロイ」→ 左上の歯車（種類の選択）→「ウェブアプリ」
9. 次のとおり設定する
   - 説明: `空き日程`
   - 次のユーザーとして実行: **ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー: **Google アカウントを持つ全員**
   - 確認: 3つとも上の値になっている（「自分」「自分のみ」のままにしない）
10. 「デプロイ」を押す
11. 「アクセスを承認」や許可画面が出たら、押さずに止まって私に知らせる。私が許可したら続ける
12. 「ウェブアプリ」の URL（`https://script.google.com/macros/s/` で始まる）をコピーして、私に見せる
13. その URL を新しいタブで開く。許可画面が出たら止まって私に知らせる
14. 画面が開いたら、次を確認して結果を報告する
    - 画面の一番下に「版 6」と「〜 のカレンダーを読んでいます」が出ている
    - 「来週」を選んで「空きを出す」を押す → 「下記の日程でしたら空いております。」で始まる文が出る
    - 右上の歯車 → 「土日も候補に入れる」にチェック → 「‹ 戻る」→「2週間」を選ぶ → 文の中に `9/19（土）` と `9/26（土）` の行がある

## 最後に報告してほしいこと

- ウェブアプリの URL
- 手順14の3つの確認の結果（出た文をそのまま）
- 途中で詰まった手順の番号と、画面に出ていた文
