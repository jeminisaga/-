# 空き日程（段階1：お試しの予定で動く版）

空いている日時を、そのまま送れる文章にする携帯向けの画面。
要件は `要件定義.md`。この版は **段階1** = Googleカレンダーには繋がず、端末に入れた予定（初回はお試しの予定）で動く。

## 動かし方

サーバー不要。`index.html` を開くだけ。

- 携帯で見せる: このフォルダをネット上に置いて（GitHub Pages など）そのURLを開く → 共有メニューの「ホーム画面に追加」
- 手元で確認: `python3 -m http.server 8000` を実行して `http://localhost:8000/aki-nittei/` を開く

## 画面

| 画面 | 何をする |
|---|---|
| メイン | 期間（今週／来週／2週間）を選ぶ → **空きを出す** → 文面が出る → **コピーする**。文面はその場で書き足せる |
| 予定（カレンダーの印） | 段階1で予定を手で入れる場所。「お試しの予定に戻す」で初期状態に戻る |
| 設定（歯車） | 時間帯、1件の長さ、前後の余白、土日、いつから出すか、1日に出す数、出し方、文面のひな形 |

設定と予定は端末の中に保存される（段階2でGoogleカレンダーに置き換える）。

## 9/9 に見せる流れ

1. 「来週」→「空きを出す」→ 文面が出るところ
2. 予定画面で予定を1つ足す → 戻ると文面が変わっているところ（「予定を入れておくと、これが出ます」）
3. 設定で文面の一文を本人の言い回しに変える → すぐ反映されるところ
4. 実際に送っている文面を見せてもらい、設定の「はじめの一文」「おわりの一文」「出し方」をその場で合わせる

## 中身

```
index.html            画面
style.css             見た目
app.js                画面の動き（保存・切り替え・コピー）
slots.js              予定 → 空き → 文面 の計算（画面に依存しない）
manifest.webmanifest  ホーム画面に置くための設定
icon.svg / icon-*.png アイコン
test/slots.test.mjs   計算部分のテスト
```

計算の決まりごと（`slots.js`）:

- 週は月曜はじまり。今週 = 今日〜日曜、来週 = 次の月曜〜日曜、2週間 = 今日から14日
- 予定の前後に余白をとり、枠の開始は30分単位に揃える
- 終日の予定がある日は候補に出ない
- 同じ日の候補は、空いている区間をまたいで散らす（10〜11、11〜12 と続けない）
- 「今日から」にしたときは、もう過ぎた時刻を出さない
