# preset の選び方と検品基準

本プロンプトは `scripts/analyze.py` の `PRESETS` にある。ここは **どれを選ぶか** と **返ってきた出力が使い物になっているか** の判断材料。

## 選択フロー

1. ユーザーが特定の一点を聞いている（「何分に○○が出る?」）→ `qa`。他のpresetで包むと余計な分析が混ざる。
2. 他人の動画を研究している → `competitor`。
3. 自分の動画で、直したい対象が決まっている:
   - 冒頭 → `hook`
   - 全体の流れ／尺 → `structure`
   - 伸びない・離脱している → `retention`
   - これから編集する → `edit`
   - 概要欄を作る → `chapters`
4. 二次利用したい → `clips`
5. 分からない → `structure` を先に1回。その結果を見て次のpresetを決める。

`structure` → `retention` → `edit` は同じ動画に対して連続で回す価値がある（全体像 → 問題箇所 → 具体的な作業指示）。逆順は無駄になる。

## 各preset

### hook
**使うとき**: 冒頭、3秒、8秒、サムネとの接続、離脱。

**出力の検品**: 画面／音声／テロップが区間ごとに分かれているか。「最初の約束」が1文で書けているか。改善案が「テンポを上げる」のような抽象論でなく、時刻と具体的な操作になっているか。

### structure
**使うとき**: 全体像、尺の妥当性、どこが長いか。

**出力の検品**: セクション境界が内容変化で切れているか（等間隔なら疑う）。「冗長な区間」に時刻と理由が付いているか。全体の型が一行で言えているか。

### clips
**使うとき**: ショート化、切り抜き、再利用。

**出力の検品**: 各候補が15-45秒で単体成立するか。文脈欠落の注意が書かれているか。最後の順位付けが、実際に強い候補を上に置けているか。

### retention
**使うとき**: 視聴維持率が悪い、尺が長すぎる、どこを削るか決めたい。

**出力の検品**: 離脱理由が「つまらない」で止まらず、間延び／話題の飛躍／画に変化がない、のどれかに分類されているか。「その場で直すなら」が撮り直し不要の案になっているか。

### competitor
**使うとき**: 他人の動画を研究、企画の型を借りる。

**出力の検品**: 真似してよい型と、真似しなくてよい演出が分かれているか。「真似しなくてよい」に理由（属人性／予算／尺）が付いているか。最後の企画案が翌日1本撮れる粒度か。

### chapters
**使うとき**: 概要欄、視聴維持、再視聴。

**出力の検品**: タイトルが全角28字以内。最初が 0:00。等間隔になっていない。貼り付け用の再掲が付いている。

### edit
**使うとき**: 自分の素材を直す、外注編集者に渡す。

**出力の検品**: 残す／切る／Bロール／テロップが全てタイムスタンプ付き。Bロールに「何の画か」が書いてある。そのまま編集指示書として渡せるか。

### qa
**使うとき**: 上に当てはまらないピンポイント質問。`--question` 必須。

**質問例**:
- 00:45付近で画面に出ている数字は何か
- CTAは何回あるか、各時刻
- デモが成功する瞬間のタイムスタンプ
- 音声だけ聞いても成立しない区間
- 話者が変わるタイミング

**出力の検品**: 質問にだけ答えているか。根拠の時刻が付いているか。分からないものを「不明」と書けているか。

## 出力が悪いときの立て直し

| 症状 | 手当て |
|---|---|
| タイムスタンプが粗い／丸まっている | `--processing static --fps 1` で該当区間を再実行 |
| 画面の文字を読み違えている | `--resolution high` ＋ `--start/--end` でその区間だけ |
| 長尺で後半が雑になる | 前半・後半に分けて2回実行する |
| 一般論しか返ってこない | `--preset qa` に切り替え、質問を1つに絞る |
| 「推測:」だらけ | 情報が映像に無い可能性が高い。preset を変えるより、質問自体を変える |
