# 🐾 My Pet Gatekeeper

うちの子（あなたが登録したペット）が SNS の使いすぎを止めてくれる Chrome 拡張機能です。
対象 SNS の累計利用時間がしきい値を超えると、登録したペットの写真が画面いっぱいに登場し、操作不能の休憩タイムを強制します。

すべての写真と設定は **端末内** に保存され、外部サーバーには一切送信されません。

## インストール（開発者モード）

1. このリポジトリをクローン
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」 → このフォルダを選択
5. ツールバーに 🐾 アイコンが追加されたら成功

## 使い方

1. アイコンをクリックしてポップアップを開く
2. 「うちの子」タブで **+ ペットを追加** から写真をアップロード（最大 5 匹）
3. 「設定」タブで使用上限・休憩時間・対象サイト・今日のペットを調整
4. 対象 SNS を普通に使う → 上限到達でペットが画面に乱入
5. 休憩時間が経過するまで待つ（操作はブロックされます）

## ファイル構成

```
manifest.json              MV3 マニフェスト
src/
  background.js            service worker（タブ監視 / 使用時間集計 / 乱入トリガー）
  content.js               オーバーレイ注入
  content.css              オーバーレイ + アニメーション
  popup.html / .js / .css  拡張アイコンのポップアップ UI
  lib/
    constants.js           デフォルト設定 / 対象 SNS リスト
    storage.js             chrome.storage.local ラッパ
    image.js               画像リサイズ + Base64 化
icons/                     アイコン（仮、後で差し替え）
```

## 開発メモ

- データは `chrome.storage.local` のみを使用（外部送信なし）
- 画像は最大辺 512px / JPEG quality 0.85 に縮小して Base64 で保存
- 使用時間は対象 SNS にフォーカスがある間のみ加算し、30 秒間隔の `chrome.alarms` で永続化
- 上限到達後の再トリガーは「累計使用時間が `usageLimitMinutes` 分さらに進むたび」
- 拡張インストール前に開いていた SNS タブには content script が注入されないため、初回は **タブをリロード** してください

## スコープ外（将来対応）

- AI 似顔絵生成（プライバシー方針との兼ね合いで保留）
- 複数ペット同時乱入 / 専用ボイス / ポーズ解除 / 共有 QR
- Firefox / Edge / Brave 対応
- スマホ版（PWA）

## テスト手順

1. `chrome://extensions` から拡張を読み込み、ペットを 1 匹登録
2. 設定タブで `usageLimitMinutes: 1`, `breakMinutes: 1` に変更してテスト
3. 対象 SNS（例: x.com）を 1 分以上アクティブに → ペットが乱入
4. 1 分後に自動でオーバーレイが消えることを確認
5. 「今日の記録」で休憩回数が +1 されていることを確認
